# CSE 110 - Lab 2: Advanced Version Control & CI

This repository contains our work for CSE 110 Lab 2 at UC San Diego.

## Lab Objectives
- Work with Git branches and pull requests
- Merge branches and resolve conflicts
- Use Git cherry-pick and squash commits
- Set up Continuous Integration using GitHub Actions
- Create release branches and version tags

## Project
For this lab, we are organizing the Ultimate Party using TypeScript and Git to manage different features, including snacks, music, and invitations.
